# Product
<!-- impeccable:product-schema 1 -->
## Platform
web — Vue interface inside a Tauri desktop application.
## Users
Personal desktop users watching folders and applying file organization rules, confirmed by the user.
## Product Purpose
Automate workspace tidiness through folder monitors, matching rules, and file actions.
## Workflows
Preserve dashboard listeners, rule creation, activity journal, statistics and settings. User authorizes workflow improvements.
## Constraints
Retain existing backend behavior. Redesign deliverable is alternative mockups, pending selection, not a replacement production UI.
