# SmartOrganizer redesign concepts

Open redesign-mockups.html directly in a browser. It needs no server or dependencies.

- Workspace: bright blue listener table and recent activity, suited to everyday scanning.
- Focus: dark slate split pane with a persistent inspector for checking matching rules and destinations.
- Flow: sage rule editor arranged as Watch, Match, Act, suited to easier rule creation.

All directions preserve Dashboard, Journal, Statistics and Settings affordances. Concept switching, page navigation, search and explanatory action feedback work. Save, settings, and file operations are illustrative. All sample paths, events and counts are synthetic.

The existing product supports Any/All matching and Move, Copy, Delete, Unlink and Rename. Mockups demonstrate extension matching and moving documents; other capabilities are not proposed for removal.

The interface uses Segoe UI, thin separators, restrained corners, explicit status labels and tabular numbers. At narrow widths, the inspector stacks below the table and navigation moves above the workspace.

These are alternatives awaiting selection, not a committed production visual system.
